# Proyecto Python IMC

## Descripción
Programa desarrollado en Python para calcular el Índice de Masa Corporal (IMC).

## Datos solicitados
- Nombre
- Edad en años
- Peso en kilogramos
- Estatura en metros

## Fórmula
IMC = peso / (estatura ** 2)

## Ejecución
Abre una terminal en la carpeta del proyecto y ejecuta:

```bash
python calculadora_imc2.py
```
