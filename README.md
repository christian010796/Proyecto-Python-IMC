# Calculadora de IMC

## Descripción
#Programa desarrollado en Python para calcular el Índice de Masa Corporal (IMC). Permite ingresar nombres, apellidos, edad, peso y estatura, validando los datos para evitar errores.

## Funcionalidades
#- Validación de campos vacíos.
#- Comprobación de datos numéricos.
#- Formateo de nombres y apellidos.
#- Cálculo del IMC con dos decimales.
#- Presentación organizada de resultados mediante f-strings.

## Instrucciones de ejecución
#1. Tener Python instalado.
#2. Descargar el archivo `calculadora_imc.py`.
#3. Abrir una terminal en la carpeta del archivo.
#4. Ejecutar el comando:

#```bash
#python calculadora_imc4.py
#```

#5. Ingresar los datos solicitados.
